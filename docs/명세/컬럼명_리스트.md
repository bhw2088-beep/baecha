   1부. 화면 표 컬럼      : 화면에 보이는 표의 한글 컬럼명 ↔ 실제 데이터 필드

   4부. 코드값 목록        : status 같은 필드에 들어가는 정해진 값들
   5부. 단위 · 형식 규칙

 [표기]  타입: str(문자) int(정수) float(소수) bool(참/거짓) list(목록) dict(묶음) datetime(날짜시간 문자열)

         필드명은 실제 코드(backend/src/orm/database.py · backend/src/services/ 등)와 똑같이 적었습니다.
