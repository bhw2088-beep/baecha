## 8. 국세청 사업자등록 API 메모

| 항목 | 내용 |
|---|---|
| 제공처 | 공공데이터포털(data.go.kr) 「국세청_사업자등록정보 진위확인 및 상태조회 서비스」 · 무료 |
| 상태조회 | 사업자번호만 → 계속사업자 / 휴업 / 폐업, 과세유형 |
| 진위확인 | 사업자번호 + **대표자명 + 개업일자** → 등록 내용과 일치 여부 (**가입 확인 목적이면 추천**) |
| 키 받기 | data.go.kr 가입 → 활용신청 → 마이페이지 인증키(Decoding) → `.env`에 `NTS_API_KEY=키` |
| 주의 | 키는 코드 · GitHub에 올리지 않음 (`.env`는 제외됨) |
| 기존 계정 | 시드 사업자번호는 예시 → 확인 대상에서 제외, **새로 가입할 때만** 확인 |

## 9. 제한 사항

> 명세대로 다 만들어도 남는 한계. 발표 질의응답 대비용.

### 9-1. 데이터

| 항목 | 제한 |
|---|---|
| LightGBM 매칭 | **가상 데이터로 학습** — 실제 수락 기록 없음, AUC 0.857은 가상 행동 모델 기준 |
| ALS 협업 필터링 | 실제 운행 기록 없이는 의미 있는 학습 불가 |
| GPS | **시뮬레이터 차량만** 움직임 — 실제 휴대폰 GPS 연동 없음 |

### 9-2. 외부 연동

| 항목 | 제한 |
|---|---|
| 국세청 API | data.go.kr 키 + 인터넷 필요, 호출 횟수 제한 있음 — 키 없으면 형식 검사(모의)만 |

## 10. 모의 데이터 기준

> "아무 값이나"가 아니라 **현실 규칙을 따르는 모의 데이터**를 만들기 위한 기준 4가지와 현재 상태

| # | 기준 | 관련 Phase | 현재 | 손 갈 정도 |
|:---:|---|:---:|:---:|:---:|
| 1 | 주문 위치 · 시간대별 콜 (가우스 + 포아송) | 1, 6 | 🟡 | 큼 |
| 2 | 사업자번호 · 번호판 (Mod-10 + Enum) | 0 | ❌ | 작음 |
| 3 | 차량 규격 · 안전율 | 1 | 🟡 | 작음 |
| 4 | GPS 지터 · 고의 이탈 (디바운싱) | 3, 6 | ❌ | 중간 |

**추천 순서: 2 → 3 → 4 → 1** (작고 시연 효과 큰 것부터, 구조 변경 큰 1번은 마지막)

### 10-1. 주문 위치 · 시간대별 콜

**기준** — 공간적 클러스터링 + 포아송 분포
- 위치: 물류 거점(서울 물류센터 · 인천항 · 평택 · 대전 허브 등)을 중심으로 **가우스 노이즈** → 거점 주변에 주문이 몰림
- 시간: **포아송 도착률**을 시간대별로 다르게 → 오전 8~9시 · 오후 6~7시 · 낮 시간 폭증

| 구분 | 내용 |
|---|---|
| 현재 | 거점 좌표는 있음 (`spatial.py`의 `HUBS`). 가상 화주(`virtual_shipper.py`)가 **거점 이름 2개를 무작위**로 고르고 **일정 간격**으로 주문 |
| 만들 것 | 거점 주변 가우스 좌표 생성, 시간대별 포아송 도착률 |
| 바뀔 파일 | `simulator/virtual_shipper.py`, `services/order_service.py` |
| 주의 | 주문 · 경로 계산이 **거점 이름** 기준 → "거점 + 실제 좌표"를 함께 들고 다니게 바꿔야 함 (4개 중 가장 큼) |

### 10-2. 사업자번호 · 차량 번호판

**기준** — 수학적 검증 규칙 + 법정 규격
- 사업자번호: **Mod-10 통과 정상 번호 셋** + **위반 · 폐업 번호 셋**을 미리 넣어 성공 · 실패 케이스 모두 시연
- 번호판: `plate_type: COMMERCIAL_YELLOW` 정의, 1톤 · 2.5톤 · 5톤 등 표준 톤수로 가상 기사 구성

| 구분 | 내용 |
|---|---|
| 현재 | 사업자번호 형식 검사 없음, `plate_type` 없음 |
| 만들 것 | `engines/compliance_engine.py` — Mod-10 검사, 번호판 용도 문자로 사업용 판정, 성공 · 실패 케이스 셋 |
| 바뀔 파일 | `compliance_engine.py`(신규), `auth_service.py`, `seed.py`, `frontend/pages/0_auth.py`, `tests/test_compliance.py`(신규) |

**확인된 사항**

| 항목 | 내용 |
|---|---|
| 시드 사업자번호 | 3개 중 **2개가 Mod-10 실패** — 현대글로비스 `211-81-36001`, LG디스플레이 `107-81-46711` → 통과 번호로 교체 필요 |
| 폐업 판정 | Mod-10은 **형식만** 확인 → 폐업 · 휴업은 **모의 목록**으로 판정 (국세청 키 있으면 실제 상태조회) |
| 번호판 규칙 | 사업용 화물차 용도 문자 `바 · 사 · 아 · 자` → `COMMERCIAL_YELLOW` |
| 실패 시연용 | 시드 기사 D-008 `부산 11가 2233` — `가`(자가용) → 실패 케이스로 활용 가능 |

**Mod-10 규칙 (참고)**
```
가중치  1 3 7 1 3 7 1 3 5   (앞 9자리에 각각 곱함)
합계 = Σ(자리 × 가중치) + ⌊9번째 자리 × 5 ÷ 10⌋
검증 숫자 = (10 − 합계 % 10) % 10  →  10번째 자리와 같으면 통과
```

### 10-4. GPS 지터 · 고의 이탈

**기준** — 가우스 지터 + 평균 주행 속도
